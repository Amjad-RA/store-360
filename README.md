## Store 360

### How to run

1. Clone the repository: `git clone https://github.com/hiroyukikuroda/store-360.git`
2. Go to the repository: `cd store-360`
3. Install all dependencies: `npm install`
4. Run the app in development mode: `npm run dev`
5. Open the app: `http://localhost:3000/`
6. Run the app in production mode: `npm run build && npm run start`
